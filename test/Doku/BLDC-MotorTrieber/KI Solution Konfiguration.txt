Hier ist ein einfaches C++ Programm für den Teensy 4.0, um den MCF8316C-Q1 über I2C so zu konfigurieren, dass der Motor läuft.
Das Programm nutzt die standardmäßige Wire-Bibliothek und berücksichtigt die spezifischen Anforderungen des Treibers, wie die 100-µs-Verzögerung zwischen den Bytes und das Senden des LSB (Least Significant Byte) zuerst.
Wichtige Hinweise vorab:
1. I2C-Adresse: In diesem Beispiel wird die Adresse 0x60 verwendet (Standardwert laut Datenblatt-Beispielen).
2. Essenzielle Parameter: Damit der Motor dreht, müssen laut Hersteller mindestens die maximale Drehzahl (MAX_SPEED) und das Stromlimit konfiguriert sein.
3. Code-frei: Da der Chip die FOC-Algorithmen intern in einer Zustandsmaschine ausführt, müssen wir nur die Registerwerte setzen; es ist kein eigener Regelungs-Code auf dem Teensy nötig.
#include <Wire.h>

// I2C Ziel-ID (Beispielwert aus dem Datenblatt)
const int M_ADDR = 0x60; 

// Funktion zum Schreiben eines 32-Bit Registers (Shadow-Register 0x80 - 0xAE)
void writeReg32(uint16_t regAddr, uint32_t data) {
  Wire.beginTransmission(M_ADDR);
  
  // 24-Bit Control Word erstellen [6, 7]
  // Bit 23: 0 (Write), Bit 22: 0 (No CRC), Bits 21-20: 01 (32-bit Data)
  Wire.write(0x10); 
  delayMicroseconds(100); // 100µs Verzögerung zwischen Bytes erforderlich [1]
  
  // Bits 15-8 des Control Words (Memory Page 0) [8]
  Wire.write(0x00); 
  delayMicroseconds(100);
  
  // Bits 7-0 des Control Words (Register Adresse) [8]
  Wire.write(regAddr & 0xFF); 
  delayMicroseconds(100);

  // Datenbytes senden (LSB zuerst!) [2]
  for (int i = 0; i < 4; i++) {
    Wire.write((data >> (8 * i)) & 0xFF);
    delayMicroseconds(100);
  }
  
  Wire.endTransmission();
}

void setup() {
  Wire.begin();
  Serial.begin(115200);
  delay(1000);

  Serial.println("Konfiguriere MCF8316C...");

  // Schritt 1: Grundkonfiguration mit empfohlenen Standardwerten [9, 10]
  // Diese Werte sind für einen zuverlässigen Start optimiert.
  writeReg32(0x80, 0x64738CA0); // ISD_CONFIG (Start-up Verhalten)
  writeReg32(0x84, 0x0B6807D0); // MOTOR_STARTUP1
  writeReg32(0x88, 0x113181B8); // CLOSED_LOOP1 (PWM Freq, FG etc.)
  
  // Schritt 2: Maximale Motordrehzahl setzen (Essenzieller Parameter) [4, 11]
  // Register 0x8E (CLOSED_LOOP4). Hier wird z.B. MAX_SPEED definiert.
  writeReg32(0x8E, 0x000004B0); 

  // Schritt 3: Geschwindigkeitseingang auf I2C umstellen [12]
  // Register 0xA4 (PIN_CONFIG), SPEED_MODE = 10b für I2C-Steuerung.
  writeReg32(0xA4, 0x00000302); 

  Serial.println("Initialisierung abgeschlossen. Motor startet...");

  // Schritt 4: Motor starten über I2C Geschwindigkeitsbefehl [13]
  // Register 0xEC (ALGO_DEBUG1). 
  // Bit 31 = 1 (Override), Bits 30-16 = Geschwindigkeit (z.B. 0x1000)
  writeReg32(0xEC, 0x800F0000); 
}

void loop() {
  // Hier könnten Telemetriedaten wie SPEED_FDBK (0x75A) ausgelesen werden [14]
}
Erklärung der Konfigurationsschritte:
• Control Word: Der MCF8316C erwartet vor den Daten ein 24-Bit Steuerwort. 0x1000 + Adresse signalisiert dem Chip, dass wir ein 32-Bit Shadow-Register beschreiben wollen.
• LSB First: Im Gegensatz zu vielen anderen I2C-Geräten müssen die 4 Datenbytes beginnend mit dem niederwertigsten Byte gesendet werden.
• Shadow-Register: Die Konfiguration erfolgt in den Adressen 0x80 bis 0xAE. Um diese dauerhaft zu speichern, müsste am Ende der Wert 0x8A500000 in das Register 0xEA geschrieben werden (EEPROM Write), was hier für den ersten Test weggelassen wurde.
• I2C Speed Mode: Damit der Motor auf Befehle vom Teensy reagiert, wird der SPEED_MODE im Register 0xA4 auf 10b (I2C) gestellt. Danach kann über das Register 0xEC (DIGITAL_SPEED_CTRL) die Drehzahl direkt vorgegeben werden.
